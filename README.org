* Bootstrapping
** Boot
0. Put a [[https://nixos.org/download.html#nixos-iso][bootable NixOS iso image]] on a USB flash drive, and boot from it

** Pick one of these two:
*** Single host
1. Prime the box
 #+begin_src shell
sudo nix --experimental-features 'nix-command flakes' run github:panchoh/Koch#silicon
#+end_src

*** NixOS Anywhere
1. Set a password for the ‘nixos’ user
 #+begin_src shell
passwd # set it to ‘nixos’
#+end_src

2. From a NixOS host
 #+begin_src shell
nixos-anywhere --flake github:panchoh/Koch#silicon nixos@silicon # set PIN to ‘nixos’
#+end_src

3. Dispose of the ephemeral NixOS Anywhere ssh key
 #+begin_src shell
gpg-connect-agent 'keyinfo --list' /bye # get the keygrip of the offending one
gpg-connect-agent 'DELETE_KEY <KEYGRIP>' /bye # さようなら
#+end_src

** Final steps

2. Manage your SSH key and then let Home Manager finish the setup
 #+begin_src shell
run0 systemctl restart home-manager-pancho.service
#+end_src

3. Optimise the storage just this once
 #+begin_src shell
nix store optimise --verbose
#+end_src

4. You are all set.  Happy hacking!

* Updating
** Self
*** With =nh=
#+begin_src shell
nh os switch --verbose --print-build-logs # or -vL
#+end_src

*** With =nixos-rebuild=
#+begin_src shell
nixos-rebuild switch --elevate=run0 --diff --verbose --print-build-logs # or --diff -vL
#+end_src

** Remote
*** With =nh=
#+begin_src shell
nh os switch --target-host silicon --verbose --print-build-logs # or -vL
#+end_src

*** With =nixos-rebuild=
#+begin_src shell
nixos-rebuild switch --elevate=run0 --no-reexec --target-host phosphorus --diff --verbose --print-build-logs # or --diff -vL
#+end_src

*** With =deploy-rs=
**** Single host
#+begin_src shell
cdf; deploy .#silicon
#+end_src

**** A group of boxen
#+begin_src shell
cdf; deploy --groups k8s
#+end_src

* Garbage Collection
** With =nh=
#+begin_src shell
nh clean all --keep-one --optimise
#+end_src

** With task
#+begin_src shell
task pristine
#+end_src
